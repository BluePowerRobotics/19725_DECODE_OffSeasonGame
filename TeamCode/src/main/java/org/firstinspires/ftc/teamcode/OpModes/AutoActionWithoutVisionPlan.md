完成自动程序AutoActionWithoutVisionBlue.java和AutoActionWithoutVisionRed.java以及有关action, 逻辑如下:
开始时车位于对应颜色的startPose，先调用ShootAction射出已有的三个球，再调用GotoEatPoseAction，每次前往对应颜色EatPose列表中当前Pose，进入EatAction执行完EatAction后，执行GoToShootingAreaAction，用ConvexPolygon类计算离车最近的发射点位置，前往该位置，然后继续调用ShootAction执行下一循环，前往EatPose列表下一位姿，直到列表遍历完或自动阶段剩余时间小于PARK_TIME_THRESHOLD_MS,执行GoToStopPose停车到对应颜色的StopPose。移动位置均使用RoadRunner的TrajectoryAction系统实现，在HypParams中设置两种颜色的所有Pose及EatPose列表
