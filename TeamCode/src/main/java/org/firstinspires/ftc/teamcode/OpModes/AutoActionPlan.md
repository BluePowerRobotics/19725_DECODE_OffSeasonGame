完成自动程序AutoActionBlue.java和AutoActionRed.java以及有关action, 逻辑如下:
开始时车位于对应颜色的startPose，先调用ShootAction射出已有的三个球，再调用SearchAction前往对应颜色的SearchPose等待，当limelight检测到3个及以上球时，进入EatAction：先启动intake，然后若为红色则向+Y方向移动EatDistance英寸，等待EatSecond秒，停止intake，向-Y方向移回原位；若为蓝色则先向-Y方向移动再向+Y方向移动。执行完EatAction后，执行GoToStartPoseAction返回对应StartPose，然后继续调用ShootAction执行下一循环，直到自动阶段剩余时间小于PARK_TIME_THRESHOLD_MS,执行GoToStopPose停车到对应颜色的StopPose。移动位置均使用RoadRunner的TrajectoryAction系统实现，在HypParams中设置两种颜色的所有Pose
