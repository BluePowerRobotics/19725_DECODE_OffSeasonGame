完成自动程序AutoActionBlue.java和AutoActionRed.java以及有关action, 逻辑如下:
开始时车位于对应颜色的StartPoseFar，先调用GoTO\oEatPose前往对应颜色的EatPoseFar，然后进入EatAction：先启动intake，然后若为红色则向+Y方向移动EatDistance英寸，等待EatSecond秒，停止intake，向-Y方向移回原位；若为蓝色则先向-Y方向移动再向+Y方向移动。执行完EatAction后，执行GoToStartPoseAction返回对应StartPoseFar，然后调用GoToShootingAreaAction，再调用ShootAction，最后执行GoToStopPose停车到对应颜色的StopPose。移动位置均使用RoadRunner的TrajectoryAction系统实现，在HypParams中设置两种颜色的所有Pose
