# 操控键位说明

## OffseasonDECODE（主 TeleOp）

### P1（一操）

| 键位      | 功能                                              |
| ------- | ----------------------------------------------- |
| 左摇杆     | **底盘移动** — 上/下 = 前进/后退，左/右 = 左移/右移              |
| 右摇杆 左右  | **底盘旋转** — 左转/右转                                |
| X       | **切换无头模式**（No-Head Mode），即切换为场地坐标系驱动（相对于机器人坐标系） |
| 左bumper | **吸取器吃球**                                       |
| 右bumper | **吸取器吐球**                                       |
| Y       | **吸取器停止**                                       |
| A       | **重置pinpoint定位到对应颜色的ResetPose**                 |

### P2（二操）

| 键位       | 功能                                                     |
| -------- | ------------------------------------------------------ |
| 左摇杆 左右   | **Turret Roll 角度调节**（仅在 MANUAL 模式下生效，增量式）              |
| 方向键 上/下  | **Yaw 角度调节**（MANUAL 模式下，每次 +/-5 deg）                   |
| 方向键 左/右  | **射手转速调节**（MANUAL 模式下，每次 +/-100 RPM，范围 0\~3000）        |
| A        | **发射开关** — 切换发射状态，开启后持续向射手供弹                           |
| X        | **循环切换瞄准模式**：`VISION → LOCALIZATION → MANUAL → VISION` |
| 右trigger | **自动瞄准模式下预载飞轮速度**                                      |

### 瞄准模式说明（P2 X 切换）

| 模式             | 行为                                        |
| -------------- | ----------------------------------------- |
| `VISION`       | **视觉 + 定位** — 使用 AprilTag 视觉和场地定位联合自动瞄准   |
| `LOCALIZATION` | **仅定位** — 不使用视觉，仅靠定位数据自动瞄准                |
| `MANUAL`       | **手动** — 通过 P2 左摇杆和方向键手动控制 Roll/Yaw/Speed |

### P1

| 键位      | 功能                                   |
| ------- | ------------------------------------ |
| 左摇杆     | **底盘移动**                             |
| 右摇杆 左右  | **底盘旋转**                             |
| 方向键 上/下 | **增大/减小 maxV**（每次 +/-0.1 in/s）       |
| 方向键 左/右 | **增大/减小 maxOmega**（每次 +/-0.05 rad/s） |
| X 键释放   | **切换无头模式**                           |

> 注意：SensitivityTest 不通过 Chassis.update()，而是直接设置 MecanumDrive 速度，用于现场调参。

## VelocityTest（定速测试）

### P1

| 键位      | 功能                              |
| ------- | ------------------------------- |
| 方向键 上/下 | **增大/减小前进速度系数 v**（每次 +/-0.1）    |
| 方向键 左/右 | **增大/减小角速度系数 omega**（每次 +/-0.1） |
| A       | **启动** — 底盘按当前 v/omega 持续运动     |
| B       | **停止** — 底盘停止                   |
| 右扳机     | **半步长模式** — 按下后方向键步长减半（0.05）    |

***

## 通用约定

- **摇杆映射遵循 FTC SDK 规范**：上推负值、下拉正值，代码内自动取反
- **无头模式（No-Head Mode）**：摇杆控制方向相对于场地坐标系，机器人朝向不影响操作方向
- **吸取器优先级**：P2 扳机 → P1 扳机 → Y 停止
- **发射状态下**：自动将吸取器设为吃球，持续向射手供弹
